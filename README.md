# 🧸 For My Favorite Person | Interactive Valentine Site

A beautiful, interactive web experience designed as a digital Valentine's surprise. This project features smooth animations, a Polaroid-style photo gallery, and a playful interactive "proposal" section.

## ✨ Features
- **Floating Teddy Intro:** A welcoming screen with a cute animated teddy.
- **Dynamic Polaroid Gallery:** Memories are displayed in a randomized Polaroid grid with handwritten captions.
- **The "Runaway" No Button:** A fun JavaScript feature where the "No" button escapes the mouse cursor.
- **Celebration Mode:** A joyful finale with falling petals (🌸) and rising bubbles (🫧) when "Yes" is clicked.
- **Responsive Layout:** Perfectly optimized for mobile and desktop screens.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3 (Flexbox, Grid, Animations)
- **Logic:** Vanilla JavaScript (ES6+)
- **Fonts:** Dancing Script & Quicksand via Google Fonts

## 🚀 Setup Instructions

   ```bash

2. Add Your Assets:

3. Run it: Open index.html in any browser.

⚙️ Customization Guide
Messages: Edit the texts array in the <script> tag to add your own personal messages.

Images: Update the myImages array with your own file names.

Colors: Change the --deep-rose and --soft-pink variables in the CSS :root section to match your favorite theme.
